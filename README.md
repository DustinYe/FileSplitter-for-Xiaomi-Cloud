# FileSplitter for Xiaomi Cloud（无损大文件拆分合并工具）

把大文件**无损**拆分成若干个不超过 4GB 的分块，方便上传到**小米云盘**等有单文件大小限制的网盘；日后下载回来后再合并还原，并通过 **SHA-256 双重校验**保证还原出的文件与原文件逐字节一致。

## 特性

- **100% 无损字节级拆分与合并**：不做任何压缩或重编码，分块即原文件的连续字节片段。
- **SHA-256 双重完整性校验**：拆分时记录每块及整文件的 SHA-256；合并时逐块校验 + 整体校验，全部通过才输出最终文件。某块损坏或未下完会精确定位到第几块，只需重下该分块。
- **防改名 / 乱序自动识别**：
  - 兼容网盘或浏览器重复下载自动添加的 `(1)` 等副本后缀（如 `a.mkv (1).001`、`a.mkv.002 (1)`）。
  - 清单文件按文件头魔数识别（改名或改扩展名均可识别）。
  - 即使分块名字彻底被改乱、甚至 `.001` 与 `.002` 名字对调，也会自动按**精确字节大小 + SHA-256** 对号入座还原。
- **单文件免安装**：体积仅约 56 KB，零第三方依赖，Windows 10 / 11 自带 `.NET Framework 4.x` 即可直接双击运行。
- **高分屏与深色模式适配**：完整适配 125% / 150% / 200% DPI 缩放；支持**跟随系统 / 浅色 / 深色**三种主题模式（含原生深色标题栏与滚动条）。

## 下载与使用

可直接在右侧 [**Releases**](../../releases) 页面下载编译好的 `FileSplitter.exe` 单文件运行。

### 拆分文件
1. 把大文件拖进窗口（或点击「浏览...」选择）。
2. 每块大小默认 **3800 MB**（`= 3,984,588,800` 字节，无论按十进制还是二进制计算均低于 4GB 上限，留有安全余量）。
3. 点击 **「开始拆分」**，将生成：
   - `原文件名.001`、`原文件名.002` … —— 数据分块
   - `原文件名.fsplit.txt` —— 校验清单（纯文本，记录每块及整文件 SHA-256）
4. 把所有分块和 `.fsplit.txt` 清单一并上传到云盘。

### 合并 / 校验
1. 把所有分块和清单下载到**同一个文件夹**。
2. 把清单或任意一个分块拖进窗口（会自动切到「合并 / 校验」页）。
3. 点击 **「开始合并」** 即可自动校验并还原原文件；点击 **「仅校验分块」** 可在不写出合并文件的情况下单独检查所有分块是否完好。

> **兜底机制**：即使 `.fsplit.txt` 清单不慎丢失，仍可拖入 `.001` 按顺序无损拼接（此时跳过哈希校验）；极端情况下甚至直接用 Windows 自带命令也能手动还原：
> ```bat
> copy /b "a.mkv.001" + "a.mkv.002" "a.mkv"
> ```

## 从源码构建

无需安装 Visual Studio 或额外 SDK，直接双击 `build.bat` 即可调用 Windows 自带的 C# 编译器生成 `dist\FileSplitter.exe`：

```bat
build.bat
```

## 目录结构

- `src/Engine.cs` —— 拆分 / 合并 / SHA-256 校验 / 改名自动匹配核心引擎（双缓冲流水线 I/O）
- `src/Theme.cs` —— 浅色 / 深色主题与高 DPI 自绘控件
- `src/MainForm.cs` —— WinForms 图形界面
- `src/app.manifest` —— DPI 感知应用清单
- `test/EngineTest.cs` —— 核心逻辑自动化测试套件（覆盖拆分、校验、合并、字节翻转损坏、缺失、改名乱序、取消清理等场景）
